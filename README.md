# Quiz 2

Maven project for a JUnit 5 test-driven development exercise, using the same setup as the Lecture 16 walkthrough: Java 14 and JUnit Jupiter 5.10.2. Classes live in the `org.example` package.

## Layout

- `src/main/java/org/example/` holds production code
- `src/test/java/org/example/` holds JUnit 5 tests

## Run the tests

From this directory:

```
mvn test
```
